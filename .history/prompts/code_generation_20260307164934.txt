* long_running MUST be true
* ports MUST contain at least one port
* healthcheck MUST be provided

* long_running MUST be false
* ports MUST be empty
* healthcheck MUST be null

frontend

* long_running MUST be true
* ports MUST contain at least one port
* healthcheck MUST be null
